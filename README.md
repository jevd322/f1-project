# f1-project

Vite + React + TypeScript starter with Tailwind CSS.

Quick start (macOS, zsh):

1. Install dependencies

```bash
npm install
```

2. Run dev server

```bash
npm run dev
```

3. Build

```bash
npm run build
```

4. Preview production build

```bash
npm run preview
```

Lint, format, typecheck:

```bash
npm run lint
npm run format
npm run typecheck
```

That's it — open http://localhost:5173 in your browser after running the dev server.
